## 本次升级核心内容

### 1. 反检测浏览器底座（Patchright + 拟人化节奏）
- 优先使用 `Patchright` 驱动本机真实 `Microsoft Edge / Google Chrome / Chromium`（保留原生 Playwright 兜底），在驱动层去除 `Runtime.enable` 等 CDP 自动化泄漏特征（可通过 `pip install -e ".[stealth]"` 或 `pip install patchright` 启用）。
- 浏览滚动改为拟人化鼠标轻移 + 多段随机滚轮滑动 + 随机阅读停顿，显著降低触发滑块风控的概率。

### 2. 真实网络 JSON 响应监听 + 小红书全链路打通
- **接口直听抗改版**：抖音（搜索 / 作者主页）与小红书（搜索 / 笔记详情 / 作者主页）均改用 `page.on("response")` 接收服务器原始 JSON 为主、页面 DOM 兜底，不再受前端混淆类名变动影响。
- **小红书多图 / LivePhoto / 主页正式落地**：
  - 搜索与主页发现完整透传 `xsec_token`，自动打开详情读取**全部无水印多图**、完整文案与互动数据。
  - 图文打包自动识别并保存小红书 **LivePhoto 实况视频**（`实况1.mp4`…），写入 `metadata.json`（`live_photo_files`），并自动匹配 `xhscdn` Referer。
  - **小红书作者主页采集**（`https://www.xiaohongshu.com/user/profile/...`）与抖音主页共用同一入口自动分流。

### 3. 多账号浏览器档案与规则健康自检
- 「平台登录」新增 **多账号浏览器档案**：一键新建、切换、删除独立 Cookie 会话目录（`default` 主账号登录态完整保留），方便高频采集换号防限流。
- 「平台登录」新增 **反检测内核与规则自检**：实时显示当前内核驱动（`Patchright` / `Playwright`）、浏览器通道，以及抖音 / 小红书最近一次采集走的是接口直听、DOM 兜底还是疑似网页改版告警。

### 4. 全站 DIY 自由度与界面精简
- **分组完整增删改 + 单条编辑**：支持创建空分组、原地改名、`仅删组`（迁回默认分组）与 `删组含词`（二次点击确认），以及单条关键词/主页行内编辑。
- **作品列表与设置升级**：作品列表补充清空、重置筛选与原链直跳；设置页新增原生文件夹选择、入库规则 `config.json` 直开、命名模板点击拼接占位符 + 实时预览、可选代理地址、北京时间昼夜主题规则。
- **更直观的顶部栏与 AI 接入**：移除冗余「快速设置」弹窗；右上角主题按钮改为**直接点击 5 模式循环**（自动切换 / 浅色拟态 / 深色拟态 / 浅色玻璃 / 深色玻璃）；「AI 接入」浓缩为一整段可直接复制给任意 AI Agent 使用的指令提示词。
