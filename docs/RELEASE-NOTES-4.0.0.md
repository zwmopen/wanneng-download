# 万能采集器 v4.0.0 发布说明

> **发布日期**：2026-11-25  
> **版本号**：v4.0.0（统一智能采集工作台重大升级）  
> **仓库地址**：https://github.com/zwmopen/wanneng-download

---

## 🌟 本次大版本升级亮点

### 1. 全新独立持久化采集引擎与桌面工作台
- **彻底告别外部闭源依赖**：内置 Playwright 持久化浏览器核心（`xhs_dl/web/native_collector.py`），不再依赖外部 `.NET .exe`。
- **多浏览器通用自适应（`Edge → Chrome → Chromium`）**：自动检测本机 Microsoft Edge 或 Google Chrome，未安装 Edge 时无缝降级至 Chrome 或内置 Chromium；默认启用原生系统沙盒，消除 `--no-sandbox` 风险警告横幅。
- **任务栏可点击展开 & 风控自动置顶**：修复旧版离屏定位导致点击任务栏无法展开窗口的问题；支持标准任务栏最小化、界面「查看采集浏览器」一键唤出，以及检测到滑块/扫码验证时自动居中置顶并恢复断点采集。
- **桌面外壳热升级机制**：[`desktop_shell/万能采集器.exe`](../desktop_shell/UniversalCollectorShell.cs) 启动时自动比对后端 `code_stamp` 与源码时间戳，存在更新时自动平滑重启本机后台服务。

### 2. 工作台界面直觉化重构
- **默认北京时区昼夜自动主题**：右上角升级为 7 模式主题菜单，默认按北京时间 `07:00–19:00` 自动切换浅色/深色并按日轮换拟态/玻璃质感，同时支持 6 种手动模式固定选择；移除设置页冗余主题区。
- **发起卡片置顶 + 真实筛选项补全**：默认停留「关键词采集」并记忆上次标签；关键词区新增 **作品类型下拉（`仅图文[默认]` / `仅视频` / `全部`）**、抖音真实 **排序** 与 **发布时间** 筛选；移除未接入的假复选框与冗余右侧边栏。
- **分组 DIY 与交互修复**：关键词库与作者库均新增「重命名分组」及皮肤化输入弹窗；修复「更多 ▾」下拉框悬停闪烁问题。

### 3. 统一「作品列表」与「AI 接入」开放化
- **合并「AI 与任务中心」**：将原独立任务页整合入「作品列表 -> 历史采集列表」及可折叠「剪贴板与实时排队任务」，与关键词、主页、单作品结果共用同一 12 列视图。
- **清晰时间与状态体系**：新增独立 **读取时间（`collected_at`）** 与默认倒序排序；明确区分 `publish_time` 与读取时间；状态文案改版为清晰中文 **`已读取未下载`** / **`已下载 N 张图`** / **`已入库·月份`**；补充 **收藏量** 筛选与排序；支持在设置中自由开关 **`metadata.json` 元数据生成/更新**。
- **通用飞书通知 & AI 接入子页**：支持用户自行填写飞书群 **自定义机器人 Webhook（免建应用）** 或 **企业自建机器人 `App ID` + `App Secret` + 群名/`oc_` 群 ID**（可折叠面板收纳）；设置新增 **「AI 接入」** 子页，提供一键复制服务地址、OpenAPI 文档链接与 AI 对话提示词模板。

## 📦 安装与升级指南

1. 拉取或下载源码：
   ```powershell
   git clone https://github.com/zwmopen/wanneng-download.git
   cd wanneng-download
   pip install -e .
   ```
2. 双击 [`启动万能采集器.cmd`](../启动万能采集器.cmd) 或 [`desktop_shell/万能采集器.exe`](../desktop_shell/万能采集器.exe)，或运行 `python -m xhs_dl.web.app`。
3. （可选）如需使用自定义入库归档规则或默认飞书配置文件，可复制 [`config.example.json`](../config.example.json) 到 `config/config.json` 后按需修改。
